Each clip on the [timeline](/video-editor/timeline) has a properties panel that shows its settings. The panel's controls depend on the type of clip.

In any properties panel, you can:

- select the pin icon, or press **⌘P**, to pin the panel
- select **×**, or press **Esc**, to close it

## Video properties

<Frame>
  <img src="/images/video properties.png" alt="The Video properties panel, with Position, Size and Rotate at the top, then Video Settings, Style, Volume, Opacity, Duration, Effect and Animation" />

| Control | What it does |
|---|---|
| **Position** (X and Y) | Sets where the clip sits in the frame. |
| **Size** (W and H) | Sets the clip's width and height. |
| **Rotate** | Sets the clip's rotation, in degrees. Select **Reset** to return to the default. |
| **Video Settings** | A collapsible section. Expand it to see its options. |
| **Style** | A collapsible section. Expand it to see its options. |
| **Volume** | Sets how loud the clip's audio is, as a percentage. |
| **Opacity** | Sets how see-through the clip is, as a percentage. |
| **Duration** | Shows how long the clip is. |
| **Effect** | Adds a camera-style effect to the clip. The section header shows the current effect. See [Effects](#effects). |
| **Animation** | Sets how the clip enters and exits. The section header shows the current enter and exit animations. See [Animation](#animation). |

The values shown in the screenshot are examples. Your clip's values will differ.

### Effects

Expand **Effect** in the Video properties panel to add and adjust an effect.

<Note>
  Not every option applies to every effect or every video. The panel shows the options that are available for the effect you choose.
</Note>

**Choose an effect**

The effect types include:

- **None**
- **Zoom**
- **Pan**
- **Ken Burns**

For talking-head footage, there are also these options:

- **Punch In**
- **Punch Out**
- **Jump Cut**
- **Drift**

**Shape the effect**

| Control | What it does |
|---|---|
| **Mode** and **Preset** | Choose how the effect behaves, or start from a preset. |
| **Direction** | Choose **In** or **Out**. |
| **Intensity** | Set how strong the effect is, or choose one of the preset intensity levels. |

**Set the focal point**

The focal point, or origin, is the part of the frame that the effect centers on.

- **Focus preview:** drag in the preview to set the zoom focal point.
- **Anchor to Face** and **Upper Third:** options for positioning the focal point.
- **Clip to Frame:** an option that controls how the effect relates to the edges of the frame.

**Set the timing**

| Control | What it does |
|---|---|
| **Effect Speed** | Sets how fast the effect plays. |
| **Starts** and **Ends** | Set when the effect starts and ends. |
| **Add segment** | Adds another segment to the effect. |
| **Easing** | Sets how the effect speeds up and slows down. |

### Animation

Expand **Animation** in the Video properties panel to set how the clip appears and disappears.

- An **Enter** animation plays when the clip appears.
- An **Exit** animation plays when the clip ends.

You set them separately. For each one, choose a preset and set its duration. To have no animation, choose **None**.

## Captions properties

<Frame>
  <img src="/images/captions properties.png" alt="The Captions properties panel, with Caption and Styles tabs, an All captions option, a Romanize button and the message No caption at current position" />
</Frame>

The Captions properties panel has two tabs:

- **Caption:** shows **All captions**, a **Romanize** button and the caption at the playhead's current position.
- **Styles:** options for how your captions look.

If you see **No caption at current position**, there's simply no caption at that point in your video. It isn't an error. Move the playhead to a point that has a caption to see it.

## Text properties

<Frame>
  <img src="/images/Text properties.png" alt="The Text properties panel, with Position, Size and Rotate, a Text Content box, and Typography settings for font, size, weight, spacing, line height, styles, alignment, transform and colors" />
</Frame>

| Section | What you can change |
|---|---|
| **Position**, **Size** and **Rotate** | Where the text sits in the frame, its width and height, and its rotation. Select **Reset** to return to the default rotation. |
| **Text Content** | The words in the text element. The character count appears below the box. |
| **Typography** | The **Font**, **Size**, **Weight**, **Spacing** and line **Height**. |
| Style buttons | Bold, italic and underline. |
| Alignment buttons | Left, center or right alignment. |
| **Transform** | A text transform option, for example **None**. |
| **Text** and **BG** | The text color and the background color. |
